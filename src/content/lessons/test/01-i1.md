title: Test types, with RAN examples
source: v1
points:
  - "<b>Functional:</b> does the feature do what the spec says? Example: handover completes with the right messages."
  - "<b>Performance:</b> how well? Example: throughput, attach time, handover interruption time."
  - <b>Interoperability (IOT):</b> does it work with every phone and chipset? Each modem vendor reads the spec a little differently.
  - <b>Regression:</b> did the new build break something that worked?
  - <b>Stress, soak, stability:</b> many users, long duration, repeated cycles. Finds leaks, slow degradation, rare races.
  - <b>Negative:</b> wrong inputs, lost messages, timer expiries, rejects.
  - <b>Conformance:</b> formal 3GPP test specs (TS 36.521 and 36.523 for LTE, TS 38.521 and 38.523 for NR) used for certification (GCF, PTCRB).
say: Functional proves it works, performance proves how well, interoperability proves it works with everyone, regression proves it still works.
