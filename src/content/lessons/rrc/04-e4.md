points:
  - <b>LTE attach:</b> Attach Request (with PDN Connectivity Request), Authentication Request/Response, Security Mode Command/Complete, Attach Accept (with Activate Default EPS Bearer Context Request), Attach Complete.
  - <b>5G SA:</b> Registration Request, Authentication, Security Mode, Registration Accept, Registration Complete, then PDU Session Establishment Request/Accept.
  - "Other LTE procedures: Tracking Area Update, Service Request (idle to connected), Detach. 5G equivalents: mobility registration update, Service Request, Deregistration."
  - "Authentication is <b>AKA</b>: the network sends RAND and AUTN, the SIM checks AUTN and answers with RES."
  - "A satellite network that works as a roaming partner adds PLMN selection to the picture: the phone must decide to use the satellite PLMN only when it has no terrestrial coverage."
say: "Attach is: request, authenticate, secure, accept with a default bearer, complete. 5G splits registration and session setup into two procedures."
trap: A reject is not a crash. Always read the cause value first.
