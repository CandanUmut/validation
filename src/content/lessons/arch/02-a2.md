title: The protocol stack, layer by layer
source: v1
points:
  - "<b>NAS</b> (UE to core): registration, authentication, session setup. The base station only relays it."
  - "<b>RRC</b> (UE to eNB/gNB): system information, connection setup, radio bearers, measurements, handover."
  - "<b>SDAP</b> (NR only, user plane): maps QoS flows to data radio bearers."
  - "<b>PDCP</b>: ciphering, integrity protection, header compression (ROHC), reordering."
  - "<b>RLC</b>: segmentation and, in acknowledged mode (AM), retransmission (ARQ)."
  - "<b>MAC</b>: scheduling, HARQ, random access, multiplexing of logical channels."
  - "<b>PHY</b>: coding, modulation, OFDM, reference signals, measurements."
  - "Control plane stack: NAS / RRC / PDCP / RLC / MAC / PHY. User plane stack: IP / (SDAP) / PDCP / RLC / MAC / PHY."
say: NAS talks to the core, RRC controls the radio link, PDCP secures, RLC makes it reliable, MAC schedules and does HARQ, PHY puts bits on the air.
trap: There are two retransmission layers. HARQ in MAC is fast. ARQ in RLC is slower and catches what HARQ missed.
