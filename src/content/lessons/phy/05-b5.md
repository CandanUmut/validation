title: Data channels, coding and reference signals
source: research
points:
- <b>Modulation:</b> PDSCH QPSK, 16QAM, 64QAM, 256QAM and, from Release 17, <b>1024QAM</b>. PUSCH up to 256QAM, plus π/2-BPSK when transform precoding is on.
- <b>NR coding:</b> LDPC for UL-SCH, DL-SCH and paging (PCH); polar codes for BCH and DCI; uplink control (UCI) uses polar, or a block code for small payloads.
- <b>LTE coding:</b> turbo code (rate 1/3) for data channels; tail-biting convolutional code for BCH.
- LTE sends <b>CRS</b> in every downlink subframe, used for measurement and demodulation.
- 'NR has no CRS. Its reference signals: <b>DMRS</b> (with PDSCH, PDCCH, PBCH), <b>CSI-RS</b> (channel measurement), <b>TRS</b> (CSI-RS for tracking), <b>PT-RS</b> (phase tracking), <b>PRS</b> (positioning) and, in uplink, <b>SRS</b>.'
- 'Transport block size starts from <code>N_info = N_RE · R · Qm · υ</code>: resource elements × code rate × bits per symbol × layers.'
say: LTE measures on always-on CRS. NR measures on SSB and CSI-RS and demodulates with DMRS that travels with the data.
trap: NR SS-RSRP is measured on the SSS resource elements, not on a CRS. Say SS-RSRP or CSI-RSRP when you quote an NR number.
