title: Throughput math you can do on a whiteboard
source: v1
points:
  - "Peak rate is roughly: REs per second x bits per symbol x code rate x layers, minus overhead (about 25%)."
  - "LTE 20 MHz: 100 RBs x 12 subcarriers x 14 symbols x 1000 per second = 16.8 million REs per second."
  - At 64QAM (6 bits), code rate near 0.9, minus overhead, one layer gives about 75 Mbps. Two layers give about 150 Mbps. That is the well-known Cat 4 number.
  - "5 MHz is one quarter of that: about 18 Mbps per layer at the very top MCS."
  - At low SINR you run QPSK with a low code rate. Then 5 MHz gives only 1 to 3 Mbps for the whole cell, shared by every user in the beam.
  - "Uplink is worse: the phone has 0.2 W and often gets only a few RBs so it can concentrate power."
say: I estimate throughput from RBs, modulation, code rate and layers, then compare with the measured number to see how far off we are and why.
trap: Cell throughput is shared. A satellite beam covers a wide area, so per-user rate depends heavily on how many users are in it.
